# The Last Verse

A browser fighting game.

Play it at https://the-last-verse.zachjohnson618.workers.dev/
(also at https://freak618.github.io/the-last-verse/)

## Music

The songs live in their own repo, [freak618/the-last-verse-music](https://github.com/freak618/the-last-verse-music), and the game plays them from that repo's GitHub Pages site. The Claude version can't load songs from other sites, so it has no music.
